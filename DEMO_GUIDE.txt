Class demonstration - Ling Yang

1. Explain the problem: prepare a scene checklist, do not invent production facts.
2. Show the two tools in tools.py and the model loop in agent.py.
3. Run: python3 agent.py --scene complete
   Show exact values and quotes; Python derives ready_for_human_review.
4. Run: python3 agent.py --scene incomplete
   Show no location, confirmed table and camera, and the ambiguity question.
   The location question is a Python template; the prop question is model-generated.
5. Run: python3 agent.py --scene complete --test-read-failure --output evidence/recovery_report.json
   Explain BEFORE running that a test flag injects one read failure.
   Show failed read -> model chooses another read -> comparison -> checked finish.
   This is a real model response to a controlled fault, not a natural outage.
6. Run: python3 verify_reports.py
   Run: python3 -m unittest discover -s tests -v
7. Explain limits: three conditions are not a broad reliability study; authentic
   quotations can still be misclassified or omit details. Human review is required.

Model role: extract, identify uncertainty, propose one action each turn.
Python role: validate, execute, return real observations, derive checked status,
reject unverified completion. Finish must match the checked observation.
Tool feedback changes the next decision, not model weights.

Commands overwrite the named evidence files. Preserve submitted evidence first.
Missing model service is a failure, not successful checklist preparation.
